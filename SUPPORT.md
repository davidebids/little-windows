# Little Windows Support

Little Windows is a local-first home organizer and optional care tracker for children, adults, and dogs.

## Contact

For help with Little Windows, bug reports, or feature requests, email:

[ebids.productions@gmail.com](mailto:ebids.productions@gmail.com)

You can also [open a GitHub issue](https://github.com/davidebids/little-windows/issues/new) for a non-sensitive bug report or feature request.

Please include the following when it is relevant:

- Your Little Windows app version
- Your iPhone, iPad, or Apple Watch model
- Your iOS, iPadOS, or watchOS version
- A short description of what happened and the steps that led to it

Do not post or email a Little Windows backup, care report, names, medical information, photos, or other sensitive personal information unless support specifically asks for the minimum information needed to investigate a problem. GitHub issues are public when this repository is public.

## Frequently Asked Questions

### Where is my data stored?

Little Windows stores its main data on your device. Depending on the sync mode you choose in **Settings → iCloud Sync**, the app can also use Apple's iCloud service for Private iCloud Sync or Family Sync. See the [Little Windows Privacy Policy](PRIVACY.md) for details.

### How do I make a backup?

Open **Settings → Data → Export JSON backup**. Save the exported file somewhere you control. Backups may contain sensitive personal and care information, so store and share them carefully.

### How do I restore a backup?

Open **Settings → Data → Import JSON backup** and choose a compatible Little Windows backup. Read the confirmation carefully because an import replaces data within the scope shown by the app.

### Why did I not receive a reminder?

Check that notifications are allowed for Little Windows in the Settings app on your device. Also confirm that the relevant reminder is enabled inside Little Windows. Delivery can be affected by system notification settings, Focus modes, device state, and schedule changes.

### How does iCloud sync work?

- **Local only** keeps Little Windows data on the current device.
- **Private iCloud Sync** uses Apple's private CloudKit database for devices signed in to the same Apple Account.
- **Family Sync** uses an iCloud share to make household data—and only the care profiles the owner explicitly opts in—available to accepted caregivers.

Family Sync is separate from Apple Family Sharing membership. Sync requires iCloud availability and may take time to propagate between devices.

### What should I do before deleting or replacing data?

Export a current JSON backup and store it safely. Little Windows explains whether an import or deletion affects only the current device, devices using Private iCloud Sync, or a Family Sync space before you confirm the action.

### Is Little Windows medical advice?

No. Little Windows records information entered by the user and provides organizational tools and pattern-based planning aids. It does not diagnose conditions, validate medication instructions, or replace professional medical or veterinary advice.

For a medical or veterinary emergency, contact local emergency services or an appropriate qualified professional. Do not wait for app support.
